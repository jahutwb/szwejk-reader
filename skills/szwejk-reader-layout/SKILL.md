# Szwejk Reader Layout

Use this skill to keep the reader experience book-like, stable, and usable on small screens.

## Rules

- Do not use continuous scroll in reader mode.
- Store progress by stable location, not by page number.
- Repaginate when font size, line height, viewport, or page width changes.
- Reserve space for footnotes at the bottom of the current page.
- Support mobile swipe and tappable controls from the first implementation.
- Include keyboard navigation and accessibility semantics.
