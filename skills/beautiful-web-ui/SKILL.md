# Beautiful Web UI

Use this skill to keep the reader from becoming a raw developer interface.

## Rules

- Prefer Vite, React, and TypeScript for this static MVP.
- Prefer Tailwind CSS for layout and styling.
- Prefer shadcn/ui components for polished, accessible UI primitives.
- Use a restrained literary/book aesthetic with generous whitespace.
- Avoid a generic dashboard look unless building admin views.
- Prioritize reader typography over decoration.
- Make mobile feel native and touch-friendly.
- Do not overuse animations.
- Use CSS variables for theme, font size, page width, and line height.
- Include light and dark theme structure even if dark mode is not fully polished yet.
